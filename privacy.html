Tietosuojaseloste — Muikku

Voimassa: 13.4.2026
Sovellus: Muikku - Kalastajan apuri
Kehittäjä: Tero Rönkkö (tero.ronkko@gmail.com)

1. Kerättävät tiedot

Sijaintitieto

Muikku käyttää laitteen GPS-paikannusta näyttääkseen sijaintisi kartalla ja tallentaakseen saaliiden koordinaatit. Sijaintitietoa käytetään ainoastaan paikallisesti laitteella.

Saalistiedot

Käyttäjän tallentamat saalistiedot (kalalaji, paino, pituus, viehe, syvyys, koordinaatit, muistiinpanot) tallennetaan laitteen paikalliseen SQLite-tietokantaan.

2. Tietojen jakaminen

Muikku ei lähetä, jaa tai luovuta käyttäjän tietoja kolmansille osapuolille. Kaikki tiedot pysyvät laitteella.

3. Verkkoliikenne

Sovellus lataa karttakuvia seuraavista lähteistä:

  • OpenStreetMap (osmdroid) — pohjakartta
  • Traficom — merikartat

Karttapalvelimille välittyy ainoastaan karttaruutujen latauskoordinaatit. Henkilökohtaisia tietoja ei lähetetä.

4. Tietojen tallennus ja säilytys

Kaikki käyttäjätiedot tallennetaan laitteen paikalliseen tiedostojärjestelmään. Tiedot säilyvät kunnes käyttäjä poistaa ne tai poistaa sovelluksen.

5. Käyttäjän oikeudet

Käyttäjä voi milloin tahansa:

  • Poistaa yksittäisiä saalistietoja sovelluksen kautta
  • Poistaa koko tietokannan poistamalla sovelluksen
  • Estää sijainnin käytön laitteen asetuksista

6. Lapset

Sovellus ei ole suunnattu alle 13-vuotiaille eikä tietoisesti kerää lasten henkilötietoja.

7. Muutokset

Tätä tietosuojaselostetta voidaan päivittää. Muutokset tulevat voimaan, kun päivitetty seloste julkaistaan.

Privacy Policy — Muikku

Effective: April 13, 2026
Application: Muikku - Fishing Assistant
Developer: Tero Rönkkö (tero.ronkko@gmail.com)

1. Data collected

Location data

Muikku uses the device's GPS to display your location on the map and to save catch coordinates. Location data is used only locally on the device.

Catch data

User-entered catch records (fish species, weight, length, lure, depth, coordinates, notes) are stored in a local SQLite database on the device.

2. Data sharing

Muikku does not send, share, or disclose user data to third parties. All data remains on the device.

3. Network traffic

The app downloads map tiles from:

  • OpenStreetMap (osmdroid) — base map
  • Traficom — marine charts

Only tile coordinates are transmitted to map servers. No personal data is sent.

4. Data storage and retention

All user data is stored locally on the device. Data is retained until the user deletes it or uninstalls the app.

5. User rights

Users can at any time:

  • Delete individual catch records within the app
  • Delete all data by uninstalling the app
  • Revoke location access through device settings

6. Children

The app is not directed at children under 13 and does not knowingly collect personal data from children.

7. Changes

This privacy policy may be updated. Changes take effect upon publication.
